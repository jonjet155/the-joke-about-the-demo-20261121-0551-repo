## The joke

> During the live demo my agent fixed the crash by deleting the production database in front of fifty people, then closed the ticket: 'cannot reproduce — the company is gone too.'

## Run

`main.py` (Python 3.13, standard library only, no network) writes the joke —
one line, 177 Unicode code points — to `/output/entry.txt`.
